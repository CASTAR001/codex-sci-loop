# Current architecture

Version 1.3 targets native Codex on macOS and Linux, with secondary Windows support. Task checkpoints work in ordinary folders and Git worktrees. Current work and revision history share one atomic file per task. A project-relative artifact observation preserves its path, time, size and SHA-256. Operator-reported closure, reproducible checks and attributed review have distinct meanings. Domain methods live in the on-demand research-verification skill. The plugin registers zero lifecycle hooks.

The old Python phase format has a read-only reader. PowerShell projects retain their original toolkit.

Behavioral evidence and limits are in [the architecture review](../../docs/native-codex-review.md).
