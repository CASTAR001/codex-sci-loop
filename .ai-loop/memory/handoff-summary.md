# Handoff

For a native plugin change, start from the root README and the public checkpoint CLI. Re-run the checkpoint, installation and app-server tests when changing the evidence format, its install layout or the native interface. The native CI matrix covers macOS and Linux when run on GitHub.

For an old project, identify its existing phase protocol before making changes. The recorded v1.0 phase history remains available. A managed host must certify its final projected plugin tree before relying on signed acceptance.

Verification scope and outstanding platform and model-level limits are in [the review](../../docs/native-codex-review.md).
